# Скіли, авторовані в цьому репо

Тека — **джерело правди** для скілів, які ми написали самі (на відміну від
зовнішніх, що ставляться менеджером у `.agents/skills/` і фіксуються в
`skills-lock.json`). Тут вони відстежуються git-ом; у `.claude/skills/` живе
лише робоча копія, яку харнес читає при старті сесії.

| Скіл | Що робить |
|------|-----------|
| [`animating-svg-for-web`](animating-svg-for-web/SKILL.md) | Анімовані SVG-діаграми та векторні ілюстрації для вебсторінок: семантичний контракт SVG, драбина технологій (CSS → WAAPI → motion → GSAP), пʼятиактна хореографія, верифікація по заморожених кадрах. Окремий довідник для ізометричних лінійних систем. |

## Встановлення

Хук `agent-guard` не пускає агента в `.claude/` та `.agents/` — це навмисно,
встановлення робить користувач:

```bash
cp -R docs/superpowers/skills/animating-svg-for-web .agents/skills/
ln -s ../../.agents/skills/animating-svg-for-web .claude/skills/animating-svg-for-web
```

Після цього перезапустити сесію — харнес читає скіли при старті. Правки
вносяться **тут**, у відстежуване джерело, після чого копія оновлюється тією ж
командою (`cp -R` перезапише теку).

## Що не тримати в цій теці

- Зовнішні скіли — вони приходять менеджером, їхнє джерело в апстрімі.
- Локальні експерименти, які не збираємось комітити, — для них `.agents/skills/`
  достатньо.
